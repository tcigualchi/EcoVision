## 🌎 Sobre o Projeto

O **EcoVision** é um projeto acadêmico desenvolvido com o objetivo de mostrar como **tecnologia, inteligência artificial e sustentabilidade** podem trabalhar juntas para contribuir com a conscientização ambiental.

A plataforma apresenta conteúdos relacionados à reciclagem, inovação sustentável e impactos provocados por diferentes tipos de resíduos.

Além da parte informativa, o projeto conta com uma ferramenta capaz de utilizar **imagens ou a câmera do dispositivo para analisar materiais**, explorando conceitos de Inteligência Artificial e reconhecimento de imagens.

A proposta é tornar o aprendizado sobre reciclagem mais **visual, interativo e acessível**.

---

## 🎯 Objetivos

- ♻️ Incentivar a conscientização sobre reciclagem.
- 🌱 Demonstrar a importância da sustentabilidade.
- 🤖 Explorar o uso de Inteligência Artificial na identificação de resíduos.
- 📚 Disponibilizar informações sobre diferentes materiais recicláveis.
- 🌎 Mostrar os impactos ambientais causados pelo descarte incorreto.
- 💡 Apresentar tecnologias e soluções voltadas para o meio ambiente.
- 💻 Aplicar conceitos de desenvolvimento web em um projeto acadêmico.

---

## ✨ Funcionalidades

### 🤖 Identificação de resíduos com IA

Um dos principais recursos do projeto é a utilização de **Inteligência Artificial para reconhecimento de imagens**.

O usuário pode utilizar a câmera ou enviar uma imagem para que o sistema realize uma análise do material apresentado.

A funcionalidade utiliza tecnologias como:

- **TensorFlow.js**
- **Teachable Machine**
- reconhecimento de imagens no navegador;
- acesso à câmera do dispositivo;
- upload e análise de imagens.

---

### 📷 Análise pela câmera

A plataforma permite iniciar a câmera diretamente pelo navegador para utilizar o modelo de reconhecimento.

Isso transforma a aplicação em uma experiência mais interativa, permitindo demonstrar na prática como técnicas de **Machine Learning** podem ser aplicadas ao processo de identificação de resíduos.

---

### 🖼️ Análise de imagens

Além da câmera, também é possível trabalhar com imagens enviadas pelo usuário.

A aplicação apresenta uma pré-visualização da imagem e disponibiliza a opção para realizar sua análise.

## 🧠 Inteligência Artificial

O repositório contém os arquivos necessários para executar o modelo de reconhecimento diretamente pelo navegador:

```text

metadata.json
weights.bin
```

Esses arquivos representam o modelo utilizado pela aplicação.

Com o **TensorFlow.js**, o processamento pode acontecer diretamente no navegador, permitindo integrar Machine Learning a uma aplicação web utilizando JavaScript.

## 🚀 Como Executar

Como o projeto utiliza tecnologias web, você pode executá-lo localmente utilizando um servidor HTTP.

### 1. Clone o repositório

```bash
git clone https://github.com/tcigualchi/EcoVision.git
```

### 2. Entre na pasta

```bash
cd EcoVision
```

### 3. Inicie um servidor local

Se você possui Python instalado:

```bash
python -m http.server 8000
```

ou:

```bash
python3 -m http.server 8000
```

### 4. Abra no navegador

```text
http://localhost:8000
```

> É recomendado utilizar um servidor HTTP em vez de abrir diretamente o `index.html`, principalmente por causa dos recursos relacionados à câmera e ao modelo de Inteligência Artificial.
